# ecommerce-node-starter-simple (Pure HTML + CSS)

Starter Node.js + Express e-commerce project using SQLite and simple custom CSS (no frameworks).

## Quick start

1. Install dependencies:
   npm install

2. Initialize the database (creates data/ecommerce.db):
   npm run init-db

3. Run the server:
   npm run dev
   (or `npm start`)

4. Open http://localhost:3000

## Notes
- Uses EJS views and plain CSS in `public/css/style.css`.
- DB initializer seeds a few products and categories.
- CSRF protection and basic session handling included.
